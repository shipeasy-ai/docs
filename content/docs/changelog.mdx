## CLI and MCP server

The CLI and the MCP server are published to npm as `@shipeasy/cli` and `@shipeasy/mcp`. Check which version you have installed:

```bash
shipeasy --version
```

Every published version is listed on the [`@shipeasy/cli` versions page](https://www.npmjs.com/package/@shipeasy/cli?activeTab=versions). Running the CLI through `npx -y @shipeasy/cli@latest` always uses the newest release — see [Install](/get-started/install).

## The dashboard and the API

The dashboard and the Admin API deploy continuously, so they have no version to pin. The [API reference](/api) is generated from the same spec the CLI and MCP server are built from, so it always matches what is live.

## The docs

Pages show when they last changed, and the whole site is versioned in the [docs repository](https://github.com/shipeasy-ai/docs/commits/main). To get an agent-readable snapshot of the current docs, see [llms.txt](/get-started/llms).
