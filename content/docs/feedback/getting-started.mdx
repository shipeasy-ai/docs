<Quickstart title="Bugs & Requests in 2 minutes" time="~2 minutes">
  <QuickstartStep
    num={1}
    label="INSTALL"
    title="Add the SDK"
    cmd="npm i @shipeasy/sdk"
  >
    Same SDK as flags and configs. No separate package, no separate API key.
  </QuickstartStep>

<QuickstartStep
  num={2}
  label="WIRE"
  title="Configure once, use everywhere"
  cmd="// app/layout.tsx
import { configure } from '@shipeasy/sdk/server';
configure({ apiKey: process.env.SHIPEASY_SERVER_KEY ?? '' });"
>
  The same single `configure()` call as the rest of the platform, with the server key.
</QuickstartStep>

  <QuickstartStep
    num={3}
    label="REPORT"
    title="File a bug from the browser"
    cmd="// Mount the devtools nub once at app boot:
import { init as initDevtools } from '@shipeasy/devtools';
initDevtools();
// Then users press Shift+Alt+B to file a bug — overlay handles
// title, repro steps, screenshot capture, and posting."
  >
    The overlay posts via `/devtools-auth` with a short-lived
    browser-scoped admin token. The bug shows up on Home, the
    project's ops queue, within seconds.

  </QuickstartStep>

<QuickstartStep
  num={4}
  label="REQUEST"
  title="Capture a feature request"
  cmd="// Same nub — users press Shift+Alt+R instead of Shift+Alt+B
// for a feature request. The form prompts for title, description,
// and use case (the fields the CLI `feedback features create`
// requires)."
>
  The request lands in the same queue on Home, filed as a feature request, where teammates can
  triage it.
</QuickstartStep>

  <QuickstartStep
    num={5}
    label="TRIAGE"
    title="From the CLI"
    cmd="shipeasy ops list --type bug
shipeasy ops list --type feature_request"
  >
    Or open **Home** in the dashboard. Either way the records live in your project.
  </QuickstartStep>
</Quickstart>
