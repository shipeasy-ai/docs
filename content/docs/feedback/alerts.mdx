## What this covers

Surveying your project for what's worth watching, then building each alert as a
full chain — emit the **event**, define a **metric** over it, and attach a
**metric-threshold alert rule**:

```bash
shipeasy metrics create …   # metric over the event (see /shipeasy:metrics:grammar)
shipeasy alerts create …    # threshold rule on that metric
shipeasy alerts list        # confirm it landed
```
